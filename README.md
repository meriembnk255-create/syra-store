# by._syraa — متجر حقيقي (Node.js بدون مكتبات)

## التشغيل
1. استضافة تدعم Node.js 18+ (Hostinger / Render / Railway / VPS).
2. ارفع الملفات: server.js, index.html, package.json
3. أمر التشغيل: `npm start`
4. متغير البيئة: `ADMIN_PASSWORD=كلمة_سر_قوية` (أول تشغيل فقط، وبعدها تتغير من الإعدادات)
5. اربط الدومين (مثلا bysyraa.com) وفعّل HTTPS.

## ملاحظات
- البيانات (منتجات/طلبات) في ملف data.json: خذ منه نسخة احتياطية، ولا تحذفه عند التحديث.
- على استضافات Render/Railway المجانية الملفات تُمسح: استعمل Disk/Volume دائم.
- كلمة السر الافتراضية admin123: غيّرها فورا من الإدارة > الإعدادات.
- الأسعار والمخزون والمجموع تُحسب في السيرفر، لا يمكن التلاعب بها من المتصفح.
